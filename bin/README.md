# Optional bundled tools

Kovatube looks here before `PATH` for `yt-dlp` and `ffmpeg`.

- macOS and Linux: `yt-dlp` and `ffmpeg`
- Windows: `yt-dlp.exe` and `ffmpeg.exe`

Files in this folder are copied next to the packaged app. Leave it empty to use tools already installed on the computer.

ffmpeg builds are GPL or LGPL. If you ship a binary, include that build's license with the release.
